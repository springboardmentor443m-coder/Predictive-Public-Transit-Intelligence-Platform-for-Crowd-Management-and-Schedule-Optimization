# Data Source

The dataset used in this project was supplied by the project user as:

`seoul-metro-2015.logs.csv`

The public dataset documentation describes this family of files as refined Seoul Metro usage data from Seoul Open Data / Seoul Metro. The `station_code` in yearly logs is intended to map to station metadata.

External reference:
https://www.kaggle.com/datasets/kimjmin/seoul-metro-usage

Official Seoul station metadata:
https://data.seoul.go.kr/dataList/OA-15442/A/1/datasetView.do

The project does not replace the supplied records with synthetic data.
