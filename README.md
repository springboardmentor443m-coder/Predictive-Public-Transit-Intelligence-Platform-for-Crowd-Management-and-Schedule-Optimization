# 🚇 MetroFlow: AI-Powered Predictive Crowd Management & Smart Transit Scheduling Platform

MetroFlow is a full-stack transit intelligence system combining an **XGBoost Machine Learning Regressor** with an automated **Smart Scheduling & Overcrowding Alert Engine** and a modern **ReactJS + Vite + Tailwind CSS Frontend** to forecast passenger loads and dispatch optimal train headways in real-time.

> **🔗 Dataset Link:** [Download Master Dataset (Excel Format)](https://docs.google.com/spreadsheets/d/1msXUYKOQ5EbkESvQkFJLWeE7W8WjB6KU/export?format=xlsx)

---

## 🚀 Quick Start Guide

### 1. Start the FastAPI Backend Server
Open a terminal in the root folder (`metroflow-backend`):
```bash
# Install Python dependencies
pip install -r requirements.txt

# Launch FastAPI on port 8000
python -m uvicorn main:app --reload --port 8000
```
- **Backend API Live**: `http://localhost:8000`
- **Interactive Swagger Docs**: `http://localhost:8000/docs`

---

### 2. Start the ReactJS Frontend
Open a second terminal in the `frontend` folder:
```bash
cd frontend

# Install Node dependencies
npm install

# Start Vite Development Server
npm run dev
```
- **Frontend Dashboard Live**: `http://localhost:5173`

## 🖥️ Frontend Components & Features

1. **Live Prediction Calculator (`PredictionCalculator.jsx`)**:
   - Origin & Destination Station Pickers (`Botanical Garden`, `Dwarka Sec 21`, `Hauz Khas`, `Kashmere Gate`, `Rajiv Chowk`) with instant swap.
   - Metro Line Corridor selector (`Blue Line`, `Magenta Line`, `Red Line`, `Yellow Line`).
   - 24-Hour Slider with automatic peak hour indicator (8–11 AM and 5–8 PM).
   - Train Capacity selector (`1,500`, `1,800`, `2,400` pax).
   - Visual Radial Occupancy Gauge (`OccupancyGauge.jsx`) with safety tier color coding.
   - Operational Overcrowding Alert Banner (`AlertBanner.jsx`) with OCC notification channels.
   - 1-Click Simulation Scenarios (`QuickPresets.jsx`) for instant peak/off-peak testing.

2. **Fleet Schedule Advisory Table (`ScheduleAdvisoryTable.jsx`)**:
   - Live schedule directives generated by XGBoost predictions.
   - Real-time search across stations, train IDs, and corridors.
   - Filter by traffic tier (🔴 Severe Rush, 🟡 Moderate, 🟢 Off-Peak) and lines.
   - Recommended headway badges (3 min, 6 min, 10 min) and CSV export.

3. **Network Analytics & Model Evaluation (`NetworkAnalytics.jsx`)**:
   - 24-Hour hourly average crowd curve with 800 pax and 1,500 pax critical danger threshold benchmarks.
   - Station Congestion rankings and line volume breakdown.
   - Machine learning pipeline validation metrics.

## 🧹 Data Cleaning, Feature Engineering & ML Pipeline

### ⚙️ Feature Engineering
- **Temporal Extraction:** Hourly breakdown (`0–23`), Day of Week, and Rush Hour binary flag (`1` for 8–11 AM & 5–8 PM, `0` otherwise).
- **Cyclical Time Encoding:** Applied $\sin(2\pi \cdot \text{hour}/24)$ and $\cos(2\pi \cdot \text{hour}/24)$ so the model learns the continuous circular 24-hour transit clock.
- **Domain Metrics:** Platform dwell time calculation and computed departure delay.
- **Categorical Encodings:** Label encoded station IDs, lines, and days of week.

### 🤖 Model Training & Accuracy (XGBoost Regressor)
Chronological split (80% Train / 20% Test):
- **$R^2$ Score:** `0.9506` (explains ~95% of passenger count variance).
- **Mean Absolute Error (MAE):** `111.33 passengers`.
- **Root Mean Squared Error (RMSE):** `140.60 passengers`.

## 🚦 Smart Scheduling Rule Engine

| Traffic Tier | Predicted Occupancy | Recommended Headway | Automated Fleet Action |
|---|---|---|---|
| 🔴 **Severe Rush Hour** | $\ge 1,500$ pax | **3 Minutes** | High-Frequency Dispatch to clear platform |
| 🟡 **Moderate Traffic** | $800 - 1,499$ pax | **5–6 Minutes** | Maintain Standard Headway |
| 🟢 **Off-Peak Flow** | $< 800$ pax | **10 Minutes** | Extend Headway (Conserve Fleet & Power) |
