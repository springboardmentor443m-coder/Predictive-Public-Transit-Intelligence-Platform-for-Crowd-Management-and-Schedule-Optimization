# MetroFlow Unified Data Dictionary & Data Lineage

This document details the exact schema, data types, value classifications, and transformation lineage across all layers of the MetroFlow system.

---

## 1. Classification of Values

Every data attribute in MetroFlow is strictly classified into one of three operational categories:

1. **OBSERVED**: Direct empirical measurements collected from official hardware, GTFS-RT Protobuf feeds, or MTA Open Data APIs (e.g., turnstile entry tap count, train geolocation).
2. **ESTIMATED**: Derived values computed using deterministic mathematical calculations on observed data (e.g., rolling 3-hour mean demand, lag features).
3. **PREDICTED**: Future values generated by trained Machine Learning models (e.g., next-hour passenger demand, station risk level).

## 2. Lineage Architecture

```
RAW DATA SOURCES
├── MTA Subway Hourly Ridership (Open Data API)
├── MTA Station Metadata (Spatial GTFS CSV)
└── MTA GTFS-RT Protobuf Feeds (Live API)
       │
       ▼
CLEANED MASTER DATASET (metroflow_master.csv)
├── Datetime alignment (hourly UTC/EST buckets)
├── Top 12 Station Complex filtering
└── Line & Borough metadata enrichment
       │
       ▼
FEATURE ENGINEERING PIPELINE (build_dataset.py)
├── Lags: lag_1h, lag_2h, lag_24h, lag_168h
├── Rolling Stats: rolling_3h_mean, rolling_24h_mean, rolling_3h_std
├── Cyclical Features: sin_hour, cos_hour, sin_day, cos_day
└── Spatial Encoders: target_encoded_station, borough_encoded
       │
       ▼
ML MODEL INFERENCE (RandomForestRegressor)
├── Predicted Passenger Count (Next Hour)
├── Station Risk Threshold Evaluation (LOW, MODERATE, HIGH, CRITICAL)
└── Feature Importance Calculation
       │
       ▼
PRESENTATION / REST API (FastAPI & WebSockets)
├── REST Endpoints (/api/v1/ml/*, /api/v1/users/*)
└── Live WebSocket Broadcaster (/api/v1/ws/events)
```

## 3. Data Schema & Field Dictionary

### A. Master Dataset Schema (`metroflow_master.csv`)

| Field Name | Data Type | Value Category | Description |
| :--- | :--- | :--- | :--- |
| `transit_timestamp` | Datetime (ISO 8601) | OBSERVED | Hourly timestamp bucket (`YYYY-MM-DD HH:00:00`) |
| `station_complex_id` | String / Int | OBSERVED | Official MTA Station Complex Identifier |
| `station_complex` | String | OBSERVED | Human-readable station complex name |
| `borough` | String | OBSERVED | NYC Borough (`Manhattan` or `Queens`) |
| `passenger_count` | Integer | OBSERVED | Total turnstile entry taps recorded in hour |
| `transfers` | Integer | OBSERVED | System-to-system transfer entry count |
| `latitude` | Float | OBSERVED | Station complex centroid latitude |
| `longitude` | Float | OBSERVED | Station complex centroid longitude |
| `routes` | String | OBSERVED | Space-separated subway routes serving complex |
| `structure` | String | OBSERVED | Physical station structure (`Subway`, `Elevated`) |
| `ada` | Boolean | OBSERVED | ADA Accessibility flag |
| `line` | String | OBSERVED | Subway trunk line name |

---

### B. Machine Learning Predictions Schema (`metroflow_predictions.csv`)

| Field Name | Data Type | Value Category | Description |
| :--- | :--- | :--- | :--- |
| `transit_timestamp` | Datetime | OBSERVED | Hourly prediction target timestamp |
| `station_complex_id` | String | OBSERVED | Target station complex ID |
| `station_complex` | String | OBSERVED | Target station complex name |
| `actual_passenger_count`| Integer | OBSERVED | True ground-truth entry passenger count |
| `predicted_passenger_count`| Float | **PREDICTED** | ML model forecasted next-hour demand |
| `absolute_error` | Float | **ESTIMATED** | $\|Actual - Predicted\|$ |
| `risk_level` | String | **PREDICTED** | Risk status (`LOW`, `MODERATE`, `HIGH`, `CRITICAL`) |

---

### C. Live Real-Time Feed Schema (GTFS-RT Normalized)

| Field Name | Data Type | Value Category | Description |
| :--- | :--- | :--- | :--- |
| `vehicle_id` | String | OBSERVED | Unique live train vehicle identifier |
| `trip_id` | String | OBSERVED | Live GTFS trip identifier |
| `route_id` | String | OBSERVED | Live subway line route (e.g., `1`, `7`, `A`) |
| `latitude` | Float | OBSERVED | Live GPS latitude position |
| `longitude` | Float | OBSERVED | Live GPS longitude position |
| `current_status` | String | OBSERVED | `INCOMING_AT`, `STOPPED_AT`, `IN_TRANSIT_TO` |
| `delay_seconds` | Integer | OBSERVED | Live schedule deviation delay in seconds |
| `passenger_count` | Null / None | **UNAVAILABLE** | Explicitly `None` (MTA does not provide live train weight sensor data) |
